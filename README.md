# YouTube Title Fixer

A small, human-written demo project for a conversational YouTube helper.

The idea is simple:
1. Connect a YouTube account.
2. Ask in plain language to change a video title.
3. Show exactly what will be changed or deleted.
4. Require an explicit confirmation for destructive actions.

This repository is intentionally a front-end demo. It does **not** contain real OAuth secrets or call the live YouTube API.

Open `index.html` locally to try it.
